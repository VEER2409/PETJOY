# PetJoy 🐾

A pet supplies shopping website built with Django.
Find food, clothes, toys, and accessories for happy pets.

## Project Goal

Build this project step by step while learning how its code works.
Use AI mainly to explain concepts and troubleshoot errors.

## Technology

- Backend: Python and Django
- Database: MongoDB
- Frontend: Django templates, HTML, CSS, and JavaScript
- Version control: Git and GitHub

## Planned Features

- A welcoming homepage with happy pets and product categories
- Product browsing, search, and category filters
- Customer signup, login, and logout
- Shopping cart with quantity controls
- Cash on Delivery checkout
- My Orders with order status
- Admin management of categories, products, and orders
- Responsive design for phones, tablets, and computers

## Product Categories

- Food
- Clothes
- Toys
- Grooming
- Beds and Accessories

## User Experience

- Clear confirmation when a product is added to the cart
- Updated cart item count
- Loading indicators during requests
- Disabled Place Order button while submitting
- Order confirmation after successful checkout
- Helpful validation messages and empty states
- Subtle animations that respect reduced-motion preferences

## Data and Security

- Keep passwords and database credentials out of Git
- Use Django authentication and backend validation
- Calculate order prices using database values
- Validate stock before placing orders
- Prevent duplicate orders from repeated submissions
- Use a separate MongoDB database named petjoy
